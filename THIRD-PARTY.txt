3. ASSETS AND MODELS (not redistributed)
--------------------------------------------------------------------------------

None of the items in this section is redistributed with GAIA; the user obtains
each one themselves at setup time. So that what a user ends up with is what was
reviewed, gaia/flame/assets/setup_assets.sh applies the following policy:

  * SMIRK's FLAME assets (landmark_embedding.npy, l_eyelid.npy, r_eyelid.npy and
    mediapipe_landmark_embedding/) are NOT downloaded. They are tracked inside the
    SMIRK submodule, pinned by gitlink to c7de404, and are symlinked from there.
  * FlashAvatar's head_template.obj is fetched from the pinned commit 5d6cf43.
  * FLAME 2020 is NOT downloaded by any GAIA script. It is licence-gated and the user
    obtains it themselves, so the licence is accepted by a person rather than worked
    around by a script; its contents are then verified by sha256.
  * setup_assets.sh ends by running gaia/flame/assets/verify_assets.py, which hard-pins
    the sha256 and byte size of every downloaded artifact and of the ten generated
    UV masks, and fails the install on any mismatch.

FLAME 2020
  Upstream : https://flame.is.tue.mpg.de
  License  : Max Planck Institute for Intelligent Systems -- license-gated,
             non-commercial. Requires accepting the FLAME license.
  Usage    : NOT REDISTRIBUTED, and not downloaded by any GAIA script. The user
             accepts the upstream license, downloads FLAME2020.zip themselves and
             unzips it into gaia/flame/assets/; setup_assets.sh refuses to run until
             it is present and verify_assets.py then checks its sha256.

MODNet
  Upstream : https://github.com/ZHKKKe/MODNet
  License  : Apache License 2.0, covering code and models alike.
  Usage    : NOT REDISTRIBUTED. Used by the optional dataset preprocessing
             pipeline for alpha mattes. The user clones MODNet and downloads

FFHQ (Flickr-Faces-HQ)
  Upstream : https://github.com/NVlabs/ffhq-dataset
  License  : Creative Commons BY-NC-SA 4.0 for the dataset and metadata;
             individual images carry their own per-image licenses.
  Usage    : NOT REDISTRIBUTED. Training data. The user downloads FFHQ and
             performs EG3D's alignment/cropping themselves; see

FlashAvatar
  Upstream : https://github.com/USTC3DV/FlashAvatar-code
  Version  : 5d6cf43
  License  : MIT License
  Usage    : NOT REDISTRIBUTED. Source of head_template.obj, which carries
